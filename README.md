# 最后一张卡有多难抽？

一个以数学家卡牌为主题的交互式概率实验。亲手抽卡、调整稀有度、观察重复卡累积，再用公式与模拟解释：为什么图鉴越接近完成，最后一张往往越难等？

**在线体验：** [difficult-last-card.netlify.app](https://difficult-last-card.netlify.app/)

## 玩法

1. 设置卡牌种类数（5 至 20 种）和稀有度倍率 `R`（1 至 8）。
2. 单抽获得 1 张卡，开 1 包获得 10 张卡。**一包的张数与卡牌种类数是两个独立概念**：卡池可以有 6 种、11 种或 20 种卡，但每包始终抽取 10 张。
3. 抽到新卡后解锁对应的数学家卡面；点击已解锁卡牌可查看百度百科条目。重复卡、新卡概率和集卡进度会实时更新。
4. 选择超过 5 种卡时，图鉴会额外赠送“我的同学”彩蛋卡。点击它可进入“我是谁？”剪影猜谜；答对或点击“我不知道”才会揭晓原图。
5. 阅读推导并运行 2,000 次 Monte Carlo 实验，对照理论期望、模拟均值和 90% 分位数。

网页底部展示真实访客的浏览与抽卡汇总。彩蛋卡和模拟实验不计入全站抽卡统计。

## 概率模型

每次抽取相互独立、有放回。稀有度为普通、稀有、传奇的卡牌分别使用权重 `1`、`1/R`、`1/R²`，再将权重归一化为每张卡的抽中概率。因此 `R = 1` 时各卡等概率；增大 `R` 会让稀有卡更难抽到。

对于 `m` 种等概率卡牌，集齐所需的**单张抽取次数** `T` 满足：

$$
\mathbb{E}[T] = mH_m = m\sum_{j=1}^{m}\frac{1}{j}.
$$

如果尚未获得的卡牌集合为 `M`，其总抽中概率为 $q(M)=\sum_{i\in M}p_i$，那么接下来连续 `k` 次都没有新卡的概率是 $(1-q(M))^k$。当只剩最后一张时，平均等待次数为 $1/p_{\mathrm{last}}$。网页还展示不等概率情形的容斥推导、等待时间分布和模拟结果。

## 本地运行

直接用浏览器打开 `index.html` 即可体验抽卡、图鉴、剪影猜谜和理论页面。全站访客统计依赖 Netlify Functions 与 Netlify Blobs，在直接打开 HTML 或普通静态服务器中不会同步。

如需生成发布目录，请安装 Node.js，然后在项目目录运行：

```bash
npm ci
npm run build
```

构建结果在 `dist/`。`build.mjs` 会复制网页、统计脚本和猜谜所需图片；`netlify.toml` 指定 Netlify 的构建命令、发布目录与函数目录。将 GitHub 仓库连接到 Netlify 后，后续推送可触发重新部署。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面、卡牌数据、交互与概率讲解；数学家卡面和公式资源已内嵌 |
